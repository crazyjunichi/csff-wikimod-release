安装与依赖

WikiMod 是一个 BepInEx 5 模组，安装前需要先把 BepInEx 装到游戏里。

步骤：

  1. 安装 BepInEx 5（按其官方说明把 BepInEx 解压到游戏根目录并启动一次游戏让其生成目录）
  2. 把 WikiMod.dll 放进游戏根目录下的 BepInEx/plugins/
  3. 启动游戏即可生效

第一次启动后会在 BepInEx/config/WikiMod.cfg 自动生成配置文件，正常情况下不需要手动改。

入口一：游戏内选项页面

打开方式：主菜单 / 暂停菜单 → 选项，往下滚动可以看到 WikiMod 的若干分组。

这里集中了日常会用到、需要开关或调数值的常用项。按分组介绍（具体每一项的标题和说明在游戏里都能看到，这里不再复述）：

  • 基础功能：游戏内 Wiki、地图、数值显示（数显）、快速查找、信息显示、CTRL 整组移动、快捷背包等
  • 提醒：动物提醒、陷阱提醒
  • 日记本：是否记录玩家动作 / NPC 动作 / 世界事件 / 状态变化等
  • 万能修改器界面缩放：调整万能修改器窗口的整体缩放

部分项后面带有"需重启"标记——修改后需要重启游戏才能生效。

入口二：万能修改器（按 ` / ~）

默认快捷键 `（键盘左上角 Esc 下方那颗，中文里也叫"波浪键"），按一下即可打开。

万能修改器是 WikiMod 中"更深层"功能的统一入口：

  • 顶部有搜索框，输入卡牌名、状态名、工具名都能直接定位
  • 主界面有一组快速入口（图标按钮），按用户使用频率排列

快速入口里的工具（按界面里的标题列出，详细操作进入对应工具后即可看到）：

  • 更多设置 — 实验性功能、数显细节、字体、徽章系统、开发者模式等高级开关；选项页面里没收的开关都在这
  • 其他 Mod 配置 — 直接编辑其他 BepInEx 模组的配置项，不需要去翻 .cfg 文件
  • 快捷键配置 — 集中调整 WikiMod 所有快捷键
  • 世界环境设定 — 蓝图研究、食物腐败、农田 / 菜园生长、容量、战斗难度等倍率
  • 提醒 — 自定义动物 / 陷阱提醒规则
  • 状态锁定管理 — 管理"锁定属性当前值"的开关
  • 搬家工具 — 批量整理与搬运卡牌
  • 脚本工具 — 编辑 / 运行 / 绑定快捷键执行脚本（脚本写法见专门的脚本指南）

除了这些工具，搜索框里还能直接搜到游戏中的卡牌、状态、NPC、蓝图等条目并跳转。

进阶：配置文件位置

所有 BepInEx 配置都保存在：

游戏根目录/BepInEx/config/WikiMod.cfg

普通使用不需要直接编辑这个文件——选项页面 / 万能修改器里的"更多设置""快捷键配置"已经覆盖了全部条目；但反馈问题或排查日志时知道这个路径会方便很多。

日志文件位于 BepInEx/LogOutput.log，发 issue 时建议附上。

Installation & Requirements

WikiMod is a BepInEx 5 mod, so BepInEx must be installed first.

Steps:

  1. Install BepInEx 5 (follow its official guide — extract it into the game root folder and run the game once so it generates the BepInEx subfolders)
  2. Drop WikiMod.dll into BepInEx/plugins/ under the game root folder
  3. Launch the game — that's it

A config file is auto-generated at BepInEx/config/WikiMod.cfg on first launch. You normally don't need to edit it by hand.

Entry 1: In-game Options Page

How to open: Main menu / Pause menu → Options, scroll down to see the WikiMod groups.

This page collects the everyday switches and numeric tweaks you'll touch most often. Listed by group (each individual switch has its own title and description in-game, so they're not repeated here):

  • Basic features: in-game Wiki, map, detail tooltips, quick find, info display, CTRL move stack, quick inventory bar, etc.
  • Alarms: animal alarms, trap alarms
  • Game journal: whether to record player actions / NPC actions / world events / status changes, etc.
  • Anything Mod scale: scale factor for the Anything Mod window

Some entries are tagged "Requires restart" — those need a game restart to take effect.

Entry 2: Anything Mod (press ` / ~)

Default hotkey: ` (the backtick key under Esc, top-left of the keyboard). Press it to open.

The Anything Mod is the unified entry for the "deeper" features of WikiMod:

  • A search box at the top — type a card name, status name, or tool name to jump straight to it
  • A row of quick-entry icons in the main view, ordered by usage

Tools available from the quick-entry icons (titles match what's shown in-game; details are visible inside each tool):

  • Advanced — experimental features, tooltip details, font, badge system, developer mode, and other advanced switches that are intentionally kept out of the Options page
  • Other Mod Configs — edit config entries from other BepInEx mods directly, no need to dig through .cfg files
  • Hotkeys — central place to remap every WikiMod hotkey
  • World Environment Settings — multipliers for blueprint research time, food spoilage, crop / garden growth, capacity, encounter level, etc.
  • Alarm — define your own animal / trap alarm rules
  • Stat Lock Manager — manage which stats are pinned to their current value
  • Move Tool — batch-organize and relocate cards
  • Script Tool — edit / run / hotkey-bind scripts (see the dedicated script guide for the script language)

Beyond these tools, the search box also indexes in-game cards, statuses, NPCs, blueprints, etc., so you can jump to them directly.

Advanced: Config File Location

All BepInEx config is stored at:

<game root>/BepInEx/config/WikiMod.cfg

You normally won't need to edit this file — the Options page plus the Anything Mod's Advanced / Hotkeys screens already cover every entry. But knowing the path helps when filing issues or digging through logs.

Log file: BepInEx/LogOutput.log — please attach it when filing a bug report.

概览

WikiMod 是一个综合性的 Card Survival: Fantasy Forest 模组，为这个卡牌生存游戏带来了从信息查询、地图导航、角色管理、自动化脚本到全功能修改器的完整增强。下面按功能类别分类介绍。

一、信息查询

🌐 实时 Wiki

与在线版网页 Wiki 基本对齐的本地 Wiki，随游戏启动、无需联网。数据实时来自游戏运行时本身，不是预先下载的快照。

  • 数据实时反映当前游戏版本和已加载的 Mod，无需手动导出
  • 自动包含其他 Mod 添加的卡牌、状态等内容
  • 中 / 英 / 日三语
  • 覆盖卡牌、状态、NPC、蓝图等大部分核心页面
  • 描述里的关键词可点击跳转，浏览路径可回退
  • 属性影响因素：清晰列出哪些卡牌、哪些动作会影响某个属性

🔢 数值显示（数显）

悬停查看卡牌、状态、特质、操作按钮的精确数值。

  • 正确显示陷阱概率、操作条件、食物评分等
  • 显示未解锁卡牌的解锁条件
  • 显示转化暂停原因、容器内部液体与液体转化
  • 显示状态相关复合状态、阶段变化时间与被动状态效果
  • 显示动作导致的后续变化与可能减少耗时的条件
  • 显示属性转移、未激活 NPC 刷新条件
  • 合并显示相同风味、相同来源的状态修改项
  • 显示调味品衰减时间
  • 显示同堆叠中的不同名卡牌
  • 可显示卡牌创建时间（在高级设置中开启）

📈 信息面板

游戏界面上显示常用辅助信息。

  • 当前季节、日期、总存活时间
  • 当前温度、月相、天气预报
  • 重量信息、蓝图信息、沙拉得分

🔍 快速查找

按 Alt 开启全局快速查找。

  • 输入中文、拼音、首字母均可搜索
  • 在场景中搜索场景物品并跳转（包括容器中、蓝图中、装备中）
  • 在蓝图界面搜索指定蓝图并跳转
  • 在地图界面搜索指定标签、掉落物，并高亮对应地图
  • 支持直接运行当前地点动作

二、地图与导航

🗺️ 游戏地图

按 M 键打开。探索界面也会显示当前区域附近的简易地图。

室外地图：

  • 显示家园、农田、陷阱、野生动物位置
  • 显示各地点地标、动植物、可探索物品
  • 显示农田、陷阱详细情况（农田是否成熟、陷阱是否触发）
  • 显示已建造道路与狩猎围栏
  • 显示动物巢穴（狐狸洞、獾洞）、山洞、尸体
  • 显示动物热力图：悬停在动物图标上可查看常去的地方，越频繁颜色越红
  • 点击地图可直接向目的地移动，支持遇到动物自动停止
  • 显示地图容量与当前属性

室内地图：

  • 多层结构展示
  • 显示每个房间内的物品
  • 点击房间可快速移动
  • 室内 / 室外快速切换

作物状态：

  • 以进度条形式显示农田、菜园的水 / 肥 / 酸 / 土质
  • 显示各属性的安全范围

🔔 提醒

  • 动物即将经过提醒

  • NPC 啃食田地、陷阱触发显示
  • 自定义提醒

附加成就系列：徽章、神秘石像、奖品。

  • 奖品：晴天娃娃、彩灯、次元箱、猛男雕像等

四、工具

📜 脚本系统

自动替你完成游戏里原本需要手动拖拽、点击、右键选动作的操作流程。把日常重复的步骤写成几行文本，一键运行。

入口：万能修改器 → 脚本工具。脚本文件存放于 BepInEx/config/WikiMod/Scripts/。

你能用脚本做什么：

  • 重复执行某个动作（比如反复砍柴、批量取水）
  • 按条件决定做什么（比如"有肉干就吃、没有就算了"，"快坏的肉干优先吃掉"）
  • 串联多个步骤（比如先加水再加料再煮）
  • 给脚本绑定独立快捷键，按一下就执行

其他特性：

  • 脚本快捷面板，常用脚本一键运行
  • 内置语法检查与中英双语帮助文档
  • 卡牌名支持中文显示名、英文名、CardTag 自动匹配
  • 支持条件判断、循环、变量、子脚本调用
  • 选择器条件过滤：[in:位置]、[has:物品]、[属性>值]，可逗号组合
  • liquid_merge 命令集中同类液体

🤖 AI 助手对接（MCP）

让支持 MCP 的 AI 助手读取你当前的游戏状态、查 Wiki、写脚本并运行。 数据仅在本机进程间流动，不会上传外部。

能直接发问的例子：

  • "离我最近的大风地形在哪？"
  • "如何打铁？"
  • "在哪里钓鲟鱼？"
  • "帮我把所有快坏的肉干吃掉"

支持的客户端：Claude Desktop / Claude Code / Codex / Cherry Studio / Cline / Cursor / Windsurf / ChatGPT 桌面端 等。

接入方式：在 AI 客户端里说

帮我添加一个 MCP server，名字 wikimod，类型 http， 地址 http://127.0.0.1:24680/mcp

让 AI 自己写入配置。或在 Claude Code 里执行：

claude mcp add wikimod --transport http http://127.0.0.1:24680/mcp

不支持 MCP 但能发 HTTP 请求的 AI 工具，把上面的地址告诉它即可。

存档工具：

建造与搬家：

  • 建造工具：一键建造房间、扩建房间、改造房间、新增家具

  • 快速进屋（开关）：进屋出屋不再需要弹窗确认

快捷键与操作：

  • 自定义功能快捷键（含游戏原生快捷键）
  • 按回车直接执行卡牌第一个按钮操作
  • 加速时间动画

特质与任务：

  • 开局后增加、删除角色特质
  • 强制完成任务

更多设置：

  • 开发者模式：可查看一些调试数据
  • 数显默认详情、数显延迟时间、数显字体
  • 显示已生效的其他 Mod 的版本及其相关配置
  • 更多实验性功能可在"更多设置"中查看

⚡ 快速添加物品

Overview

WikiMod is an all-in-one mod for Card Survival: Fantasy Forest, bringing a comprehensive enhancement suite — from information lookup, map navigation, character management, automation scripts, all the way to a full-featured game modifier. The features below are grouped by category.

1. Information Lookup

🌐 Live Wiki

A modern wiki mostly aligned with the online web wiki, launched alongside the game — no internet required. Data is read live from the running game, not from a pre-downloaded snapshot.

  • Live data — reflects the current game version and loaded mods, no manual export needed
  • Auto-includes cards and statuses added by other mods
  • Available in Chinese / English / Japanese
  • Covers cards, statuses, NPCs, blueprints, and most other core pages
  • Keywords inside descriptions are clickable; navigation history can be rewound
  • Stat influence factors: clearly lists which cards / actions affect a given stat

🔢 Detail Tooltip

Hover to see precise values for cards, statuses, perks, and action buttons.

  • Correctly displays trap chance, action conditions, food score, etc.
  • Shows unlock conditions for locked cards
  • Shows conversion pause reasons, container inner liquids, and liquid conversions
  • Shows compound statuses, phase change durations, and passive status effects
  • Shows follow-up changes caused by actions and conditions that may reduce required time
  • Shows attribute transfers and respawn conditions for inactive NPCs
  • Merges identical flavours and identical status modifier sources
  • Shows seasoning / coating decay times
  • Shows differently-named cards within the same stack
  • Card creation time can be enabled in advanced settings

📈 Information Panel

Useful supporting information shown across the game UI.

  • Current season, date, and total survival time
  • Current temperature, moon phase, weather forecast
  • Weight, blueprint, and salad-score info

🔍 Quick Find

Press Alt to open a global quick-find search.

  • Search by Chinese, pinyin, or initials
  • In a scene: searches scene items and jumps to them (including inside containers, blueprints, and equipment)
  • In the blueprint UI: searches and jumps to a target blueprint
  • In the map UI: searches by tag or drop and highlights the matching maps
  • Can directly run an action for the current location

2. Map and Navigation

🗺️ Game Map

Press M to open. A simplified nearby map is also shown in the exploration UI.

Outdoor Map:

  • Shows home, farms, traps, and wild animal positions
  • Shows landmarks, plants/animals, and explorable items per location
  • Shows farm and trap details (crop maturity, trap triggered state)
  • Shows built roads and hunting fences
  • Shows animal burrows (fox dens, badger dens), caves, and carcasses
  • Animal heatmap: hover an animal icon to see frequented areas; the higher the frequency, the redder the tile
  • Click anywhere to walk to that destination, with optional auto-stop on animal encounters
  • Displays map capacity and current map attributes

Indoor Map:

  • Multi-floor structure
  • Shows items per room
  • Click a room to move there quickly
  • Quick switch between indoor and outdoor

Crop Status:

  • Progress bars for water / fertilizer / acidity / soil quality on farms and gardens
  • Safety ranges for each attribute

🔔 Alerts

  • Animal-incoming alert
  • Trap-triggered alert
  • NPC crop grazing and trap-trigger display
  • Custom alerts

  • Logs key animal events such as crop grazing and trap triggers

Off by default. Enable manually in game settings.

4. Tools

📜 Script System

Automates the drag, click, and right-click-an-action steps you'd normally do by hand. Write down a routine in a few lines of text and run it with one keystroke.

Entry: Anything Mod → Script Tool. Script files live under BepInEx/config/WikiMod/Scripts/.

What you can do with scripts:

  • Repeat an action (e.g. chop wood or fetch water in batches)
  • Decide based on conditions ("eat jerky if any, otherwise skip"; "eat the most-spoiled jerky first")
  • Chain multiple steps (e.g. add water → add ingredients → cook)
  • Bind a hotkey to any script for one-keypress execution

Other features:

  • A quick-launch panel to run frequently used scripts in one click
  • Built-in syntax checker and a bilingual reference guide
  • Card names accept the localized display name, English name, or CardTag
  • Supports conditions, loops, variables, and sub-script calls
  • Selector condition filters: [in:location], [has:item], [attribute>value], comma-combinable
  • liquid_merge command to consolidate same-type liquids

🤖 AI Assistant Integration (MCP)

Lets MCP-capable AI assistants read your current game state, browse the Wiki, write scripts, and run them. Data flows only between local processes — nothing is uploaded externally.

Examples you can ask directly:

  • "Where's the nearest windy terrain?"
  • "How do I forge iron?"
  • "Where can I fish for sturgeon?"
  • "Eat all the jerky that's about to spoil"

Supported clients: Claude Desktop / Claude Code / Codex / Cherry Studio / Cline / Cursor / Windsurf / ChatGPT Desktop, etc.

Setup: tell your AI client —

Add an MCP server named wikimod, transport http, URL http://127.0.0.1:24680/mcp

…and let the AI write the config for you. Or run in Claude Code:

claude mcp add wikimod --transport http http://127.0.0.1:24680/mcp

AI tools without MCP support but capable of HTTP requests can simply be given the URL above.

⚙️ Anything Mod

Press ` (the key below ESC) to activate. Covers data lookup, modification, debugging, and assistance.

Data Lookup and Modification:

  • Search any in-game data
  • Get any item with custom stats and enchantments
  • Modify any data on existing cards
  • Custom Durability progress bars: display any attribute as a progress bar on card face, with customizable height, label, and colors
  • View / modify any status; clear staleness; lock values (auto-lock can persist across sessions)
  • Get cards x10
  • Don't stack cards with different names (toggle)
  • All cards deletable (toggle)

NPCs and Environment:

  • View / modify NPC status; move NPC near the player
  • Create, delete, or duplicate NPCs (have multiple companions of the same type)
  • Add or remove NPC perks at runtime
  • Adjust NPC respawn rate (full health on respawn)
  • Freely shift game time while keeping seasons in sync
  • Adjust global rates: blueprint research / food spoilage / skill staleness / animal respawn / farm growth / garden growth / farm yield / garden yield / map capacity / encounter difficulty

Save Tools:

  • Switch save mode (Safe / Checkpoint / Realistic)
  • Save repair
  • Unlock all blueprints
  • Exit without saving

Build and Move:

  • Build Tool: build, expand, remodel rooms; add furniture
  • Move Tool: migrate any object (including rooms) on the current map to another map in one click
  • Fast house entry (toggle): no popup confirmation when entering / leaving houses

Hotkeys and Operations:

  • Customize feature hotkeys (including native game hotkeys)
  • Press Enter to execute a card's first button action
  • Speed up time animations

Perks and Quests:

  • Add or remove character perks after game start
  • Force-complete quests

More Settings:

  • Developer mode: view debug data
  • Detail Tooltip default expanded / delay time / font
  • Show active other mods and their configurations
  • More experimental features available in More Settings

⚡ Quick Add Items

Right-click a slot in the blueprint or container UI to open a menu and quickly add available items.

  • Sortable by attribute preference (e.g. prioritize high-quality items)
